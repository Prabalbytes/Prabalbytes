### ⚡ One-time setup for the snake animation

The snake graphic is generated by a GitHub Action in your own repo, not a third-party server — so it won't break like the earlier widgets did. In your `Prabalbytes/Prabalbytes` repo, add this file:

`.github/workflows/snake.yml`
```yaml
name: Generate Snake Animation
on:
  schedule:
    - cron: "0 0 * * *"
  workflow_dispatch:
  push:
    branches: [ main ]

jobs:
  generate:
    runs-on: ubuntu-latest
    steps:
      - uses: Platane/snk/svg-only@v3
        with:
          github_user_name: Prabalbytes
          outputs: dist/github-contribution-grid-snake.svg
      - uses: crazy-max/ghaction-github-pages@v4
        with:
          target_branch: output
          build_dir: dist
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
```
Commit it, then run the workflow once manually from the **Actions** tab. It'll create an `output` branch holding the SVG the README line above points to — after that it regenerates daily on its own.
